# Level Up Fitness - AI Virtual GX Coordinator

Proposal and design for an AI agent that takes over the administrative core of the Group Exercise
(GX) Coordinator role at Level Up Fitness: weekly timetable coordination with GX instructors,
publishing, cover management, payroll compilation, performance monitoring and instructor quality
tracking.
